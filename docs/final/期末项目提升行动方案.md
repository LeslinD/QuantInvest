# QuantInvest 期末项目提升行动方案总览

编写日期：2026-06-16

期末方案按投研系统组织：

```text
研究假设 -> 数据与证据 -> 超因子构造 -> 组合生成 -> 回测/模拟盘 -> 归因诊断 -> 修正方案 -> 再测试
```

闭环主线：金融设计解释方案理由，量化实现保证每轮实验可复现，归因诊断决定下一轮修改位置。

## 系统定位

期末系统命名为：

**体育大事件热度-适配度驱动的 A 股模拟投资系统**

系统定位为小型事件驱动投研闭环：

| 闭环 | 核心问题 | 期末交付 |
|---|---|---|
| 事件闭环 | 哪些体育事件值得交易，哪些只观察 | 赛事库、分层评分、剔除理由 |
| 证据闭环 | 股票和事件到底如何相关 | 标的证据表、链条评分、人工审阅记录 |
| 热度闭环 | 热度从哪里来，热的是事件还是股票 | 赛事热度、股票热度、热度匹配因子 |
| 超因子闭环 | 多个基础指标如何变成可交易信号 | 超因子定义、权重约束、消融实验 |
| 持仓闭环 | 为什么买这些、买多少、为什么不买其他 | 中期/期末持仓对比、单股归因 |
| 风控闭环 | 收益是否来自过高风险暴露 | 单票、行业、事件、现金、止损、对冲情景 |
| 迭代闭环 | 一轮实验后如何继续提升 | 诊断分类、修改记录、再测试门槛 |
