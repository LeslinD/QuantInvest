# 第一轮优化方案与测试结果

## 本轮目标

本轮把期末规划中的“金融方案”和“系统实现”接起来，先完成可审计的第一轮优化：

1. 沿用中期后已经跑通的行情、因子、回测和模拟订单流水线。
2. 只在已有模拟订单对应的可交易股票池内重排仓位，不新增证据不足的股票。
3. 给综合因子、单票上限、行业上限、现金保留和对冲处理写入配置。
4. 生成最终订单、风险报告、对冲报告、诊断报告和下一轮行动清单。

## 与规划文件的对照

`02_真实数据与金融方案设计.md` 要求先从金融角度回答三件事：事件是否有交易意义、股票是否和事件匹配、仓位是否能解释和控制风险。本轮采用五个综合因子：

| 综合因子 | 本轮处理 |
|---|---|
| `EventOpportunity` | 用事件暴露得分表达事件机会 |

| `AttentionConfirmation` | 用热度/关注度字段确认事件被市场关注 |
| `MarketTiming` | 用动量字段控制入场时点 |
| `TradableRiskQuality` | 用流动性和低波动字段控制交易质量 |

`03_量化实现与自动化规划.md` 要求输出最终因子面板、期末模拟订单、风险报告、对冲报告、实验登记和诊断报告。本轮已生成：

## 已确认的方案

本轮新增 `configs/strategy_final.json`。配置把金融约束固定下来：

| 约束 | 数值 | 说明 |
|---|---:|---|
| 事件总仓位上限 | 25% | 体育事件交易只占小仓位 |
| 单票上限 | 10% | 防止海信视像单票过度集中 |
| 行业上限 | 20% | 防止同一链条拥挤 |
| 现金下限 | 75% | 以现金作为课程原型的主要风险缓冲 |
| 买入股数 | 100 股整数倍 | 符合 A 股普通股票买入规则 |

综合因子权重采用金融先验，不在第一轮用收益曲线反向拟合：

| 因子 | 权重 |
|---|---:|
| 事件机会 | 25% |
| 股票链条匹配 | 25% |
| 关注度确认 | 20% |
| 市场时点 | 15% |
| 可交易与风险质量 | 15% |

这个设计处理了两个未确认问题：

1. 中期模型里低波动因子权重达到 40.69%，解释上偏“风险偏好”，没有突出体育事件和标的映射。本轮把事件机会和股票链条匹配合计设为 50%。
2. 中期模拟仓位里海信视像占入选仓位 66.34%。本轮单票上限设为 10%，把入选仓位占比降到 53.40%。

## 仍未确认的方案

本轮没有把以下内容写成交易信号：

| 问题 | 本轮结论 | 下一轮动作 |
|---|---|---|
| 百度指数、微信指数自动抓取 | 可作为热度数据来源，但接口和授权不稳定 | 先用人工导入模板记录关键词、日期、原始值和截图索引 |

## 最终测试结果

运行命令：

```bash

python3 -m quant_sports_event.run_research_loop --root /workspace/coursework/QuantInvest --as-of 2026-05-26
```

测试结果：

| 项目 | 结果 |
|---|---:|
| 单元测试 | 14 项通过 |
| 完整回测净收益 | 11.04% |
| 滚动样本外验证净收益 | 2.30% |

| 指标 | 当前组合 | 第一轮优化后 |
|---|---:|---:|
| 总仓位 | 18.09% | 18.73% |

第一轮结果更适合期末展示：总仓位基本稳定，单票风险下降，订单仍满足 100 股整数倍。海信视像保留核心地位，因为其世界杯赞助链条证据最强；中体产业和共创草坪提高权重，用体育运营和体育设施链条降低单一显示设备暴露。

## 诊断结论

系统自动标出五个下一轮问题：

| 问题 | 证据 | 下一轮处理 |
|---|---|---|
| 样本偏少 | 滚动样本外验证只有 3 笔交易 | 扩展事件库 |
| 完整回测和样本外差距大 | 11.04% 对 2.30% | 冻结参数，减少参数自由度 |
| 因子不均衡 | 旧模型低波动因子权重 40.69% | 使用综合因子权重边界 |
| 仓位集中 | 海信视像原占入选仓位 66.34% | 单票上限降至 10% |
| 奥运事件不适配 | 巴黎奥运 T-60_T-10 CAAR 为 -5.00% | 作为高热低适配压力测试，不提高仓位 |
