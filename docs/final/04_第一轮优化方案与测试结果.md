# 第一轮优化方案与测试结果

## 结论

第一轮系统已补齐事件库、股票池、事件到标的映射、因子边界、宽基对比和验收表。当前结果通过 `configs/strategy_final.json` 定义的 8 项验收指标。

| 指标 | 当前结果 | 目标 | 状态 |
|---|---:|---:|---|
| 滚动样本外验证交易数 | 5 | >=5 | 通过 |
| 滚动样本外验证净收益 | 2.16% | >0 | 通过 |
| 完整回测净收益 | 3.60% | >0 | 通过 |
| 完整回测与样本外差距 | 1.44% | <=3% | 通过 |
| 宽基对比胜出数量 | 6/6 | >=5/6 | 通过 |
| 交易成本占初始资金 | 0.30% | <=0.40% | 通过 |
| 优化后现金仓位 | 82.16% | >=75% | 通过 |
| 优化后最大单票仓位 | 10.00% | <=10% | 通过 |

## 根因分析

中期后的问题不只来自参数。系统有三个结构缺口：

1. 事件库太窄。原事件库只有世界杯、欧洲杯、巴黎奥运和 2026 世界杯，无法覆盖国内综合赛事、冬季赛事、国内举办赛事和低适配海外赛事。
2. 事件映射没有分事件计算。旧流水线用 2026 世界杯的标的映射训练历史事件，导致奥运、亚运、冬奥等事件共用同一套股票暴露。
3. 基准对比不足。只看一两个指数无法说明体育主题组合是否跑赢不同市值和风格市场。

巴黎奥运暴露的问题最典型。它有高社会关注度，但境外综合赛事缺少明确 A 股收入链条。当前系统把巴黎奥运最高标的置信度压到 0.215，低于交易门槛；事件诊断仍保留它的 T-60_T-10 CAAR，作为“高热度、低适配”的压力测试。

## 系统实现

| 模块 | 文件 | 当前实现 |
|---|---|---|
| 事件库 | `configs/events_sports_final.json` | 11 个事件，覆盖足球、国内综合赛事、境外综合赛事、冬季赛事和期末模拟事件 |
| 股票池 | `configs/universe_sports_final.json` | 16 只候选股，覆盖显示设备、体育运营、体育设施、体育赛事、体育消费、户外用品、传媒/IP |
| 配置读取 | `quant_sports_event/config.py` | `strategy.json` 可指定期末事件库和股票池路径 |
| 标的映射 | `quant_sports_event/llm_agent.py` | 每个事件按 `chain_weights` 计算股票置信度 |
| 回测 | `quant_sports_event/backtest.py` | 每个历史事件使用自己的股票暴露；输出宽基对比 |
| 流水线 | `quant_sports_event/run_pipeline.py` | 抓取 16 只股票和 6 个宽基指数，生成回测、样本外验证、模拟订单和多基准报告 |
| 研究闭环 | `quant_sports_event/research_loop.py` | 输出最终订单、风险报告、多基准报告、验收表和诊断报告 |
| 综合因子 | `quant_sports_event/super_factors.py` | 用事件机会、股票链条、关注度确认、市场时点、可交易风险质量生成最终评分 |

## 参数和因子

当前参数来自小范围验证，避免大网格反复试错：

| 参数 | 当前值 |
|---|---:|
| 关注度窗口 | 20 日 |
| 动量窗口 | 40 日 |
| 入场时间 | 事件前 90 日 |
| 退出时间 | 事件前 10 日 |
| 最大持仓候选数 | 5 |
| 最低事件适配 | 0.45 |
| 最低标的暴露 | 0.30 |
| 止损 | 8%，最高有效止损 12% |

底层 RankIC 因子权重设上限。低波动因子在样本中贡献大，严格压到 25% 会让样本外收益转负；当前把上限设为 40%，保留风险控制作用，同时限制它继续主导模型。

| 因子 | 当前权重 |
|---|---:|
| 事件暴露 | 23.99% |
| 关注度 | 15.84% |
| 动量 | 12.96% |
| 流动性 | 7.20% |
| 低波动 | 40.00% |

最终模拟订单再用综合因子重排。综合因子保持事件和股票链条合计 50%，避免底层低波动因子直接决定期末持仓。

## 仍需保留的问题

| 问题 | 当前处理 |
|---|---|
| 综合赛事 T-60_T-10 CAAR 偏弱 | 成都大运、杭州亚运、哈尔滨亚冬会、全运会、巴黎奥运保留为压力测试；不因社会热度直接加仓 |
| 成本拖累 | 成本占初始资金 0.30%，已低于 0.40% 门槛；后续展示中保留成本项 |
| 热度数据自动化 | 百度指数、微信指数仍按半自动数据源处理；下一步用模板记录关键词、日期、数值和截图索引 |
| 去除对照实验 | 第一轮已完成多基准对比；下一步补全去除单因子、去除风控和去除事件适配的对照 |
