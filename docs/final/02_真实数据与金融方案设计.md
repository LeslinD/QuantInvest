# 阶段二：真实数据与金融方案设计

阶段目标：只从金融和现实投资角度设计方案。这里不讨论代码怎么写，只回答“什么事件值得交易、什么标的值得配、仓位为什么这样给、风险为什么可控”。

## 核心结论

最终金融方案以 2026 世界杯为核心模拟事件，定位为：

**在国内关注度可验证、A 股受益链条可解释、市场热度已启动但未过热的体育大事件中，构建小仓位、可归因、可风控的事件驱动模拟组合。**

期末优化同时评价收益、解释力、风险控制和低适配事件过滤能力。

## 现实依据

### 体育产业具备长期底层逻辑

国家统计局和国家体育总局公告显示，2023 年全国体育产业总产出 36,741 亿元，增加值 14,915 亿元，占 GDP 比重 1.15%；体育服务业增加值占体育产业增加值 72.7%。国务院办公厅 2025 年意见提出，到 2030 年体育产业总规模超过 7 万亿元。

金融含义：体育产业具备长期增长背景，上市公司收益链条分化很大。事件驱动策略交易“赛事预期和注意力扩散”，不替代长期基本面研究。

### 官方赛事日程提供确定性事件源

| 事件 | 官方日期 | 金融用途 |
|---|---:|---|
| 2022 卡塔尔世界杯 | 2022-11-20 至 2022-12-18 | 历史核心样本 |
| 2024 欧洲杯 | 2024-06-14 至 2024-07-14 | 足球同类扩展样本 |
| 2024 巴黎奥运会 | 2024-07-26 至 2024-08-11 | 高热低适配压力测试 |
| 2026 米兰冬奥会 | 2026-02-06 开幕，2026-02-22 闭幕 | 冰雪/IP/体育消费样本 |
| 2026 世界杯 | 2026-06-11 至 2026-07-19 | 期末模拟交易核心事件 |
| 2026 爱知-名古屋亚运会 | 2026-09-19 至 2026-10-04 | 亚洲综合赛事未来观察 |
| 2027 亚洲杯 | 2027-01-07 至 2027-02-05 | 足球且与国内关注度相关 |
| 2027 篮球世界杯 | 2027-08-27 至 2027-09-12 | 篮球扩展事件，A 股适配需低仓验证 |

入库原则：官方日期提供事件确定性；交易理由还需要国内关注度和 A 股链条适配。

### 本地回测给出的金融结论

`outputs/results/event_study_summary_2026-05-26.csv` 显示：

| 事件 | T-60 到 T-10 CAAR | 正 CAR 比例 | 解释 |
|---|---:|---:|---|
| 2022 世界杯 | +26.54% | 90% | 足球世界杯对当前 A 股候选池最强 |
| 2024 欧洲杯 | +3.18% | 70% | 有预热，但强度弱 |
| 2024 巴黎奥运会 | -5.00% | 30% | 社会热度高，但当前 A 股候选池适配弱 |

该结果说明：奥运会热度可以很高，但当选股的标的链条不匹配时，组合需要降低仓位。

### A 股交易现实约束

上交所交易机制要求 A 股买入通常按 100 股整数倍下单，主板普通股票存在日涨跌幅限制。金融方案必须尊重这些约束，因此“理论权重”还要转成“可提交股数”和“实际成交金额”。

## 事件分层方案

| 层级 | 事件类型 | 交易含义 | 仓位处理 |
|---|---|---|---|
| S | 世界杯、中国队强相关亚洲杯、国内举办大型综合赛事 | 国内关注度高，A 股链条较清晰 | 可作为核心交易事件 |
| A | 欧洲杯、冬奥会、亚运会 | 热度高，但链条分化 | 中低仓，必须看适配度 |
| B | 篮球世界杯、世俱杯、热门体育 IP 节点 | 关注度或 A 股链条不稳定 | 小仓验证 |
| C | 抽签、赛程、门票、赞助、国家队名单 | 前置信号，不一定直接交易 | 只用于热度监测或调仓触发 |

最终事件评分：

```text
EventScore = 0.30 * OfficialCertainty
           + 0.25 * DomesticAttention
           + 0.25 * AShareFit
           + 0.10 * LifecycleTradability
           + 0.10 * DataObservability
```

交易门槛：

- `OfficialCertainty < 1`：不交易。
- `AShareFit < 0.45`：只观察，不交易。
- `EventScore < 0.70`：不进入核心模拟盘。
- 综合赛事若 `DomesticAttention` 高但 `AShareFit` 低，最高仓位不超过 10%。

## 标的链条设计

期末股票池按现金流或注意力传导链条分层，避免只列“体育概念股”。

| 链条 | 金融逻辑 | 核心证据要求 | 当前代表 |
|---|---|---|---|
| 显示设备/大屏 | 世界杯观看和品牌赞助直接强化显示设备心智 | 官方赞助、产品关联、流动性 | 海信视像 |
| 场馆/草坪/LED | 赛事基础设施和场景建设 | FIFA/赛事资质、海外订单、主营占比 | 共创草坪、奥拓电子 |
| 体育运营/赛事服务 | 体育产业政策和赛事活动扩容 | 主营覆盖赛事、体育彩票、认证、运营 | 中体产业、力盛体育 |
| 传媒/彩票关注 | 比赛关注带来传媒、竞猜、广告情绪 | 彩票/传媒业务证据、股吧热度、成交确认 | 粤传媒等需再证据化 |
| IP 文创/衍生品 | 吉祥物、授权商品、礼赠品 | 明确授权或历史爆款，不可泛化 | 元隆雅图更适合冬奥/IP事件 |
| 体育消费/器材 | 赛事带动健身和运动消费 | 产品需求、渠道、动销或订单 | 舒华体育、金陵体育 |
| 食品饮料/夜间消费 | 观赛场景带动啤酒、零食 | 赛事期消费数据或品牌合作 | 可作为扩展，不宜主仓 |
| 旅游出行/酒店 | 国内举办赛事更强，海外赛事较弱 | 举办地与国内消费链条 | 仅国内赛事或入境赛事 |

### 选股映射分层

专业投资者先判断事件冲击能否传导到上市公司，再决定是否买入。期末股票池按以下等级管理：

| 等级 | 定义 | 例子口径 | 仓位含义 |
|---|---|---|---|
| L1 直接链条 | 官方赞助、赛事供应商、明确产品或订单 | 海信视像的 FIFA 赞助、共创草坪的 FIFA 资质类证据 | 可进入核心池 |
| L2 强间接链条 | 与观赛、场馆、体育运营高度相关，但缺少本次赛事直接订单 | 体育运营、LED、场馆服务 | 可进入交易池，仓位低于 L1 |
| L3 注意力链条 | 热度可能带动交易情绪，但收入链条弱 | 传媒、彩票、IP 衍生品 | 小仓观察或去除对照验证 |
| L4 泛体育概念 | 只有概念标签，无当期证据 | 泛体育消费、器材概念 | 不作为核心持仓 |
| L5 噪声误配 | 热度来自非赛事原因，或业务方向与赛事无关 | 题材混淆、偶然成交放大 | 剔除 |

该分层纠正一个常见误区：回测里涨过的股票不一定就是好标的。股票缺少 L1/L2 证据时，即使历史窗口收益好，也只能标记为“待解释异常”，不直接提高期末仓位。

标的评分：

```text
StockFit = 0.30 * BusinessRelevance
         + 0.20 * EventEvidence
         + 0.20 * AttentionCoMovement
         + 0.15 * Tradability
         + 0.15 * RiskQuality
```

任何标的没有明确业务证据时，只能进入观察池，不能进入核心持仓。

证据最低要求：

| 字段 | 要求 |
|---|---|
| `chain_level` | L1-L5，必须有人工审阅结论 |
| `evidence_items` | 至少两条来源，优先年报、公告、官网、官方赞助或赛事资质 |
| `event_specificity` | 说明证据是否指向本次赛事，避免泛体育长期逻辑 |
| `attention_sync` | 赛事热度和股票成交/热榜是否同步 |
| `risk_flags` | 业绩、估值、流动性、监管、涨跌停、过热 |
| `decision_reason` | 买入、观察、剔除的一句话理由 |

## 热度体系设计

热度必须拆三层：

| 热度 | 回答的问题 | 数据来源 | 使用方式 |
|---|---|---|---|
| `EventHeat` | 事件是否被社会关注 | 百度指数、微信指数、GDELT/新闻量、微博/媒体话题 | 决定事件是否进入预热状态 |
| `StockHeat` | 相关股票是否被资金交易 | 成交额冲击、换手率、东方财富人气、股吧讨论 | 决定是否可以入场 |
| `HeatStockFit` | 热度是否落在对应标的链条上 | 事件关键词与标的证据、股价/成交共振 | 防止奥运等高热低匹配误导 |

最终注意力因子：

```text
AttentionFinal = EventHeat * StockHeat * StockFit * DirectionGate
```

`DirectionGate` 用来防止追高：若 5 日涨幅过大、换手或成交额分位进入极端高位，则降低仓位。

## 综合因子设计

期末先把底层指标合成五个综合因子，再生成最终信号。每个综合因子对应一个金融问题。

| 综合因子 | 解决的问题 | 组成 |
|---|---|---|
| `EventOpportunity` | 这个赛事是否值得交易 | 官方确定性、国内关注度、赛事层级、事件生命周期、数据可观测性 |
| `StockLinkage` | 这只股票是否真能映射赛事 | 业务相关、官方证据、收入链条、链条等级、事件特异性 |
| `AttentionConfirmation` | 热度是否从事件传到股票 | 赛事搜索/新闻热度、成交额冲击、热榜、股吧讨论、热度共振 |
| `MarketTiming` | 当前是否适合买入 | 距事件天数、动量、短期过热、预期兑现风险 |
| `TradableRiskQuality` | 仓位是否可交易、可风控 | 流动性、波动率、交易成本、涨跌停、行业集中度 |

初始金融权重：

```text
CoreSignal =
  0.25 * EventOpportunity
+ 0.25 * StockLinkage
+ 0.20 * AttentionConfirmation
+ 0.15 * MarketTiming
+ 0.15 * TradableRiskQuality
- RiskPenalty
```

权重理由：

| 权重块 | 理由 |
|---|---|
| `EventOpportunity + StockLinkage = 50%` | 本项目以事件驱动为主，事件和标的映射主导信号 |
| `AttentionConfirmation = 20%` | 注意力研究支持搜索、新闻、异常成交量，但注意力也可能导致追高 |
| `MarketTiming = 15%` | 动量有研究基础，但在事件交易中只能辅助择时 |
| `TradableRiskQuality = 15%` | 课程模拟盘必须尊重流动性、成本和 A 股交易约束 |

后续回测可以微调权重。事件逻辑保持主导地位。单次迭代中任一综合因子权重变化不超过 5 个百分点，除非有明确去除对照实验和人工审阅记录。

## 期末持仓原则

以 2026-05-26 决策、2026-05-27 订单为同口径模拟。中期代码基线持仓为海信视像、共创草坪、中体产业，总目标仓位 18.09%。

期末金融方案控制仓位提升节奏：

| 规则 | 金融理由 |
|---|---|
| 核心事件总仓位 20%-30%，极强信号最多 40% | 体育事件属于主题交易，不能替代全账户资产配置 |
| 单股上限 10%-12% | 防止单一概念或单一流动性冲击 |
| 单行业上限 20%-25% | 防止全仓押注显示设备或体育运营 |
| 低适配事件上限 10% | 奥运会等综合赛事可热，但未必对应 A 股收益链条 |
| 现金保留不低于 60% | 普通 A 股账户下，现金是最稳妥的风险对冲 |
| 过热减仓 | 事件驱动常见“预期兑现”，热度极端时不追买 |

## 推荐的金融持仓逻辑

期末展示系统如何得出持仓：

1. 海信视像可作为 2026 世界杯核心候选，因为 FIFA 官方确认其为 FIFA World Cup 26 Sponsor，且与显示设备和观赛场景直接相关。
2. 共创草坪可作为场馆/足球设施链条候选；它与世界杯直接订单关系需要进一步验证，权重低于海信。
3. 中体产业可作为体育运营代表；其世界杯直接受益弱于显示设备，适合作为分散仓位。
4. 粤传媒、元隆雅图、舒华体育等需要当日热度、证据和可交易性共同支持，不能只靠“体育概念”入选。
5. 百度/微信/新闻热度与股票热度不共振时，组合保持低仓或只观察。

## 优越性展示标准

期末用三类指标证明优化效果：

| 维度 | 指标 | 说明 |
|---|---|---|
| 收益 | 净收益、超额收益、分事件收益 | 与中期代码基线、PDF 主观仓位同时对比 |
| 风险 | 最大回撤、单股集中度、行业集中度、现金保护、止损率 | 证明收益没有依赖更激进仓位 |
| 解释力 | 事件适配、热度匹配、因子贡献、未入选原因 | 回答老师对持仓分析和归因的要求 |

## 金融侧迭代规则

一轮回测或模拟盘完成后，按以下顺序复盘：

| 诊断问题 | 金融判断 | 下一轮动作 |
|---|---|---|
| 哪些持仓赚钱或亏钱 | 是赛事逻辑兑现，还是市场/行业 beta | 若只是 beta，降低事件结论强度 |
| 哪些高分股票没买或买少了 | 是风控约束限制，还是证据漏采 | 回到标的证据或组合约束模块 |
| 哪些入选股票缺少解释 | 是否只是历史回测碰巧有效 | 降级为观察，不进入核心结论 |
| 奥运/综合赛事表现弱 | 是热度不够，还是 A 股链条弱 | 保留为低适配压力测试 |
| 组合收益更高但集中度更高 | 是否用更高风险换收益 | 标记为风险补偿，暂不判定优化成功 |
| 去除对照实验去掉某因子更好 | 因子可能是噪声或方向错误 | 降权或剔除，记录原因 |

只有当“收益/风险/解释力”至少一项改善，且其他两项没有明显恶化时，下一轮修改才算通过。
