# 中期阶段归档

冻结日期：2026-06-13

- `deliverables/`：中期文档和 PPT 交付物，来自 `docs/midterm/`。
- `code_snapshot/`：当前代码快照，包括 `quant_sports_event/`、`configs/`、`tests/` 和 `reports/` 生成脚本。
- `results/run_outputs/`：中期实验结果表和 JSON 摘要。
- `results/data_snapshots/`：中期行情快照。
- `results/ppt/`：PPT 图表数据、图片资产和预览图。
- `results/report_previews/`：报告预览图。
- `results/intermediate/`：中期 PPT 制作和审阅过程中的中间工作目录。
